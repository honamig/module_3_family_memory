# Family Memories

Family Memories is a web application designed to organize and display family photos and memories in one place. Users will be able to view photo albums and add photos with titles, dates, and descriptions. I am creating this project to learn how to build dynamic web applications using Python and Django.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Install Python and Django
2. Open the project folder in VS Code and install the required dependencies
3. Rund python manage.py migrate to set up the database
4. Run python manage runserver in the terminal

Instructions for using the software:

1. Open the home page to view the available photo albums
2. Select an album to view its photos
3. Use the Add Photo form to upload a photo and enter its little, date, and description
4. Submit the form to add the photo to the album
